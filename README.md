# Zepto Data & AI Platform

End-to-end AI/ML engineering capstone project.

## Modules

- `data_pipeline/` — Web scraping, cleaning, currency conversion, SQLite, and SQL analysis.
- `analytics/` — Titanic dataset profiling, EDA, predictive modeling, and regression.
- `support_assistant/` — Zepto policy RAG assistant using LangGraph, ChromaDB, and FastAPI.
